# Sirin Music

Нативный Android-клиент для сервера [musik](https://github.com/torwin-job/musik). Музыкальная библиотека, персональные подборки и радио, которое учится твоему вкусу — с интерфейсом Material 3 и системным управлением воспроизведением.

Kotlin, Jetpack Compose и AndroidX Media3. Android 8.1 и новее.

## Sirin Music 2.0

Версия 2.0 обновляет главный экран, профиль, настройки и подключение. Вход доступен по QR, имени и паролю или API-токену. Аккаунт, профили, устройства и серверные настройки открываются в отдельных окнах.

Стабильные APK доступны в [Releases](https://github.com/fenixvd/SirinMusic/releases). Основная ветка — `master`, разработка ведётся в `dev`.

## Sirin Music 2.1

Паспорт трека в плеере, рекомендации по избранному и обработка повторных событий воспроизведения. Интерфейс доступен на русском и английском; язык выбирается в настройках оформления, по умолчанию используется язык системы.

## Sirin Music 2.1.1

Кнопки управления и перемотка закреплены внизу плеера. Обложка, информация о треке, паспорт и очередь прокручиваются отдельно и не сдвигают кнопки.

## Возможности

- **Библиотека:** поиск треков, исполнителей и альбомов, отдельный экран избранного.
- **Радио и подборки:** рекомендации сервера, персональные миксы, треки, исполнители и альбомы по избранному на главной.
- **Плейлисты:** создание, название и описание, добавление и удаление треков, изменение порядка. Повторяющиеся треки сохраняют собственные записи в плейлисте.
- **Избранное и обучение вкуса:** сердечки сохраняют треки, исполнителей и альбомы; оценки «нравится» и «не нравится» обучают профиль рекомендаций. Дизлайк не переключает трек автоматически.
- **Системный плеер:** фоновое воспроизведение, шторка и экран блокировки, пауза, предыдущий и следующий трек, кнопка лайка. Возврат назад использует историю серверной сессии.
- **Тексты песен:** обычный текст и синхронный LRC, подсветка строк, следование за воспроизведением и переход к строке по нажатию.
- **Оформление:** системная, светлая и тёмная темы, цвета из обоев на Android 12+, десять встроенных палитр, нижняя навигация или боковая панель на широком экране.
- **Подключение:** QR с камеры или изображения, вход по имени и паролю либо токену, проверка сервера перед сохранением. API-токен хранится зашифрованно и исключён из резервных копий Android.
- **Профиль радио:** границы новизны, недельная статистика, настроения, скрытые записи и ссылки на радио.
- **Аккаунты:** смена пароля, создание и выбор профилей, управление устройствами и токенами; приглашения и права пользователей для администраторов. Управление аккаунтом требует HTTPS и отдельного входа.
- **Сервер:** адрес, порт, музыкальная папка и подключение телефона. Доступность сохранения и перезапуска зависит от прав и возможностей сервера.
- **Синхронизация:** восстановление действующей сессии на паузе, сохранение позиции и передача управления между устройствами при поддержке сервера.
- **Фото артистов:** фотографии с сервера с запасной обложкой и общим кешем изображений.
- **Обновления:** отдельный экран проверки, загрузки и установки подписанных стабильных APK. Проверки при запуске и в фоне выключены по умолчанию.

Очередь и рекомендации выбирает сервер. Конец фиксированного плейлиста останавливает воспроизведение. API, аудио и обложки используют общий сетевой клиент; авторизация ограничена настроенным сервером. При недействительном токене приложение возвращается ко входу.

## Подключение

1. Установи APK, собранный локально или опубликованный через Releases этого репозитория.
2. Нажми «Сканировать QR-код» и наведи камеру на код из веб-интерфейса musik (*Профиль → Настройки → «Показать QR»*) — адрес и токен подставятся сами. Код можно отсканировать и системной камерой: ссылка `musik://connect` откроет приложение. QR также можно выбрать из изображения. Или укажи адрес сервера и войди по имени и паролю либо введи API-токен.
3. После загрузки библиотеки выбери радио, подборку или трек.

QR распознаётся на устройстве (ZXing), без Google Play services и сетевых запросов.

Клиент использует musik API 1.0.0. Телефон подключается к серверу по сети — например, через домашний Wi-Fi или VPN. Для подключения через недоверенную сеть используй HTTPS; HTTP поддерживается для локальных установок.

Адрес сервера и токен задаются при подключении. Тексты песен берутся с сервера. Офлайн-загрузка, редактор правил умных плейлистов и импорт/экспорт плейлистов пока не реализованы.

## Сборка

Нужны JDK 21 для Gradle, JDK 17 для компиляции, Android SDK Platform 37 и Build Tools 37.0.0. Оба JDK устанавливаются заранее, автоматической загрузки в сборке нет. Target SDK — Android 16 / API 36, минимальная версия — API 27.

Укажи путь к SDK в `ANDROID_HOME` или в локальном, исключённом из Git файле `local.properties` через `sdk.dir`.

```sh
./gradlew :app:assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

```sh
./gradlew :app:testDebugUnitTest :app:lintDebug
```

Тесты используют локальный HTTP-сервер и проверяют избранное, операции с плейлистами, повторяющиеся записи, переходы по очереди и возврат назад, оценки, тексты, ошибки авторизации и ограничение передачи токена своим сервером. Отдельно проверяются LRC и завершение фиксированного плейлиста.


## CI и релизы

`Android CI` запускает unit-тесты, Android Lint и сборку debug APK на push и pull request в `master` и `dev`. APK и отчёты доступны в артефактах GitHub Actions.

`Android Release` собирает подписанный APK по тегу `vX.Y.Z` либо вручную для существующего тега. Коммит тега должен принадлежать истории `master`. Отдельная задача публикации выкладывает проверенный APK и SHA-256 в GitHub Releases. Для публикации нужны секреты подписи; приватного ключа в репозитории нет.

Настройка ключа, список секретов и команды локальной release-сборки описаны в [docs/RELEASING.md](docs/RELEASING.md).
