# Sirin Music

[English](README.en.md) | Русский

<p align="center">
  <a href="https://play.google.com/store/apps/details?id=ru.rainedev.sirinmusic"><img src="https://play.google.com/intl/ru_ru/badges/static/images/badges/ru_badge_web_generic.png" width="180" alt="Доступно в Google Play"></a>
</p>

Нативный Android-клиент для сервера [musik](https://github.com/torwin-job/musik). Музыкальная библиотека, персональные подборки и радио, которое учится твоему вкусу — с интерфейсом Material 3 и системным управлением воспроизведением.

Sirin Music — клиент: библиотека, профили и история хранятся на твоём сервере musik, приложение подключается к нему по адресу и учётной записи. Без рекламы, подписок и слежки — исходный код открыт ([GPL-2.0](LICENSE)).

**Нет своего сервера? Попробуй демо:** [demo-music.rainedev.ru](https://demo-music.rainedev.ru) — логин `demo`, пароль `musik_demo` 

## Google Play и GitHub — в чём разница

| | Google Play | GitHub (APK из релизов) |
| --- | --- | --- |
| Обновления | автоматически через Google Play | встроенный экран проверки и установки подписанных APK из GitHub Releases (проверки выключены по умолчанию) |
| `REQUEST_INSTALL_PACKAGES` | нет | есть — нужно для установки APK |
| Функции | идентичные | идентичные |

Подпись у обеих сборок одна и та же — можно свободно переключаться между каналами без переустановки и потери данных.

## Возможности

- **Библиотека:** поиск треков, исполнителей и альбомов, отдельный экран избранного.
- **Радио и подборки:** рекомендации сервера, персональные миксы, воспроизведение исполнителя, альбома или запуск радио от трека.
- **Плейлисты:** создание, название и описание, добавление и удаление треков, изменение порядка. Повторяющиеся треки сохраняют собственные записи в плейлисте.
- **Избранное и обучение вкуса:** сердечки сохраняют треки, исполнителей и альбомы; оценки «нравится» и «не нравится» обучают профиль рекомендаций. Дизлайк не переключает трек автоматически.
- **Повтор трека:** кнопка в плеере зацикливает текущую композицию.
- **Кеш музыки:** ближайшие треки очереди заранее скачиваются на диск, чтобы паузы в сети не рвали воспроизведение; лимит настраивается (100 МБ–1 ГБ), очистка — в «Хранилище».
- **Системный плеер:** фоновое воспроизведение, шторка и экран блокировки, пауза, предыдущий и следующий трек, кнопка лайка. Возврат назад использует историю серверной сессии.
- **Тексты песен:** обычный текст и синхронный LRC, подсветка строк, следование за воспроизведением и переход к строке по нажатию.
- **Оформление:** системная, светлая и тёмная темы, цвета из обоев на Android 12+, десять встроенных палитр, нижняя навигация или боковая панель на широком экране.
- **Подключение:** QR с камеры или изображения, вход по имени и паролю либо токену, проверка сервера перед сохранением. API-токен хранится зашифрованно и исключён из резервных копий Android.
- **Профиль радио:** границы новизны, недельная статистика, настроения, скрытые записи и ссылки на радио.
- **Аккаунты:** смена пароля, создание и выбор профилей, управление устройствами и токенами; приглашения и права пользователей для администраторов. Управление аккаунтом требует HTTPS и отдельного входа.
- **Сервер:** адрес, порт, музыкальная папка и подключение телефона. Доступность сохранения и перезапуска зависит от прав и возможностей сервера.
- **Синхронизация:** восстановление действующей сессии на паузе, сохранение позиции и передача управления между устройствами при поддержке сервера.
- **Фото артистов:** фотографии с сервера с запасной обложкой и общим кешем изображений.
- **Обновления (GitHub-версия):** отдельный экран проверки, загрузки и установки подписанных стабильных APK. Проверки при запуске и в фоне выключены по умолчанию. В Play-версии обновления доставляет Google Play.

Очередь и рекомендации выбирает сервер. Конец фиксированного плейлиста останавливает воспроизведение. API, аудио и обложки используют общий сетевой клиент; авторизация ограничена настроенным сервером. При недействительном токене приложение возвращается ко входу.

## Подключение

1. Установи приложение: из [Google Play](https://play.google.com/store/apps/details?id=ru.rainedev.sirinmusic), [GitHub Releases](https://github.com/fenixvd/SirinMusic/releases) или [F-Droid](https://f-droid.org) (заявка на включение подана).
2. **Нет своего сервера?** Введи демо-сервер `demo-music.rainedev.ru`, логин `demo`, пароль `musik_demo`.
3. Есть свой сервер: нажми «Сканировать QR-код» и наведи камеру на код из веб-интерфейса musik (*Профиль → Настройки → «Показать QR»*) — адрес и токен подставятся сами. Код можно отсканировать и системной камерой: ссылка `musik://connect` откроет приложение. Или укажи адрес сервера и войди по имени и паролю либо API-токену.
4. После загрузки библиотеки выбери радио, подборку или трек.

QR распознаётся на устройстве (ZXing), без Google Play services и сетевых запросов.

Клиент использует контракты musik API 1.0.0. Сервер должен быть доступен с телефона: для локальной установки нужна домашняя сеть или VPN. Для подключения через недоверенную сеть используй HTTPS; HTTP поддерживается для локальных установок.

В приложении нет встроенного адреса сервера или токена. Тексты песен должны быть доступны на сервере. Офлайн-загрузка, редактор правил умных плейлистов и импорт/экспорт плейлистов пока не реализованы.

## Конфиденциальность

Sirin не отправляет данные аналитикам: музыкальная история живёт на твоём сервере, кеш обложек и музыки — локальный. Подробности — в [политике конфиденциальности](https://rainedev.ru/sirin/privacy/).

## Сборка

Нужны JDK 21 для Gradle, JDK 17 для компиляции, Android SDK Platform 37 и Build Tools 37.0.0. Конфигурация Gradle позволяет загрузить нужные JDK. Target SDK — Android 16 / API 36, минимальная версия — API 27.

Укажи путь к SDK в `ANDROID_HOME` или в локальном, исключённом из Git файле `local.properties` через `sdk.dir`.

```sh
./gradlew :app:assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

```sh
./gradlew :app:testDebugUnitTest :app:lintDebug
```

Тесты используют локальный HTTP-сервер и проверяют избранное, операции с плейлистами, повторяющиеся записи, переходы по очереди и возврат назад, оценки, тексты, ошибки авторизации и ограничение передачи токена своим сервером. Отдельно проверяются LRC и завершение фиксированного плейлиста.

Сборка для Google Play (без GitHub-обновлений, AAB):

```sh
./gradlew -PplayStore=true :app:bundleRelease
```

## CI и релизы

`Android CI` запускает unit-тесты, Android Lint и сборку debug APK на push и pull request в `master` и `dev`. APK и отчёты доступны в артефактах GitHub Actions.

`Android Release` собирает подписанный APK по тегу `vX.Y.Z` либо вручную для существующего тега. Коммит тега должен принадлежать истории `master`. Отдельная задача публикации выкладывает проверенный APK и SHA-256 в GitHub Releases. Для публикации нужны секреты подписи; приватного ключа в репозитории нет.

AAB для Google Play собирается локально: `./gradlew -PplayStore=true :app:bundleRelease`. Порядок подписи и публикации описан в [docs/RELEASING.md](docs/RELEASING.md).
