# Sirin Music 2.1.0

Версия `2.1.0`, код `6`.

- Добавлен паспорт трека: формат, битрейт, частота, каналы, BPM, тональность, LUFS, год, длительность, жанры и персональные счётчики. Поля без значений скрываются; паспорт не мешает воспроизведению при ошибке сети.
- Интерфейс, ошибки, уведомления и подписи доступности переведены на английский; русский сохранён.
- В настройках оформления появился выбор языка: как в системе (по умолчанию), русский или English. Выбор сохраняется, на Android13+ используется системная настройка языка приложения.
- На главной появились рекомендации треков, исполнителей и альбомов по избранному. Их можно обновить отдельно; изменения избранного обновляют рекомендации автоматически.
- Повторные события окончания или пропуска трека используют один ID. Повторный ответ для того же прослушивания не сбрасывает позицию плеера.
- При ошибке формата плеер один раз пробует совместимый MP3-поток с сохранением позиции. Неудачный трек не считается намеренным дизлайком; серия ошибок ограничивает автоматические переходы.
- Ошибка файла на паузе и ошибки сети или авторизации не переключают трек автоматически.
- Ранкер v3 и смена «глав» радио работают на сервере musik; приложение использует его рекомендации и очередь.
