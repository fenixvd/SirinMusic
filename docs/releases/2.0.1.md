Исправлены переключение треков из избранного, пауза при отключении наушников и переход из уведомления в плеер.

- После запуска песни из избранного кнопка «Дальше» переключает треки в полной очереди избранного.
- Отключение наушников ставит музыку на паузу, в том числе если запуск ещё ожидает ответа сервера. Повторное подключение само по себе не возобновляет звук.
- Нажатие на уведомление воспроизведения открывает экран «Сейчас играет».

APK подписан прежним сертификатом и устанавливается поверх 2.0.0 с сохранением настроек. Проверены 83 автоматических теста, debug/release lint и работа на физическом телефоне.
