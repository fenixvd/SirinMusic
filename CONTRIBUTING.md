# Участие в проекте

Предложения и сообщения об ошибках можно отправить через Issues. В описании укажи текущее поведение, ожидаемый результат и шаги воспроизведения. Pull request направляй в ветку `dev`; старайся решать в нём одну конкретную задачу.

Используй Gradle Wrapper и инструменты, описанные в README. Перед отправкой изменений выполни:

```sh
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

Добавляй тесты, когда они проверяют значимый контракт API или поведение воспроизведения. Операции с очередью должны использовать серверную сессию, оценки должны оставаться отдельными от избранного, а токены не должны попадать в логи или запросы к сторонним адресам.

Сохраняй согласованность интерфейса с Material 3, добавляй понятные подписи для экранных дикторов и проверяй компактные и широкие экраны. Изменения сервиса воспроизведения проверяй на устройстве, включая работу в фоне.
