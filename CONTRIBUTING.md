# Участие в проекте

Буду рад сообщениям об ошибках и предложениям в [Issues](https://github.com/fenixvd/SirinMusic/issues). Для ошибки полезны версия приложения, шаги воспроизведения, ожидаемый результат и то, что произошло на самом деле.

Pull request принимаю в ветку `dev`. Удобнее обсуждать и проверять изменения, когда один PR решает одну задачу.

## Проверка изменений

Для сборки используются Gradle Wrapper и инструменты из [README](README.md). Основные проверки:

```sh
python3 -m unittest discover -s tools -p 'test_*.py'
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

Тесты особенно полезны для API, очереди и воспроизведения. Изменения плеера также проверяются на устройстве: в фоне, через уведомление и с гарнитурой.

## Интерфейс и поведение

Sirin использует Material 3 и поддерживает компактные и широкие экраны. Подписи кнопок доступны экранным дикторам; их стоит сохранять и при добавлении новых элементов.

Очередью управляет серверная сессия. Избранное и оценки радио — отдельные функции: сердечко сохраняет запись, а лайк или дизлайк обучает рекомендации.

Настройки оформления и подключения хранятся в приложении, профиль радио — на сервере. Автоматическая проверка обновлений по умолчанию выключена. API-токен используется только для настроенного сервера и не попадает в логи или запросы к сторонним адресам.

Устройство приложения подробнее описано в [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md), выпуск версий — в [docs/RELEASING.md](docs/RELEASING.md).
