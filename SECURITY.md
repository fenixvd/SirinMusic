# Безопасность

Если нашли уязвимость в Sirin, сообщите о ней через приватное сообщение об уязвимости в GitHub. Если эта возможность недоступна, можно открыть Issue с просьбой о приватном канале связи — без описания эксплуатации и секретных данных.

Пожалуйста, не публикуйте API-токены, ключи подписи, частные адреса серверов и логи с личными данными в открытых Issues.

## Подключение к серверу

Sirin подключается к серверу, адрес которого указан в настройках. Для доступа через недоверенную сеть используйте HTTPS. HTTP поддерживается для локальных установок.

API-токен плеера хранится зашифрованно и исключён из резервных копий Android. Для управления аккаунтом используется отдельный вход по HTTPS; пароль и сессионные cookie не сохраняются на диск.

## Подпись и обновления

Ключ подписи APK хранится вне репозитория и используется GitHub Actions через секреты. Android проверяет подпись при установке и разрешает обновление приложения только совместимым сертификатом.

Обновления загружаются из стабильных GitHub Releases отдельным HTTP-клиентом. Перед установкой Sirin проверяет размер и SHA-256 файла, имя пакета, версию, совместимость Android и сертификат подписи. API-токен musik не отправляется на GitHub.

Автоматическая проверка обновлений при запуске и в фоне по умолчанию выключена. Ручная проверка доступна в настройках; установку подтверждает пользователь в системном окне Android.
